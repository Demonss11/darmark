Добро пожаловать в darmark

Это демонстрационный документ для прототипа AI-ассистента.

Возможности

  • Редактирование Markdown
  • Предпросмотр в реальном времени
  • AI-ассистент для правки документов
  • Создание Lua-плагинов

Пример кода

function on_activate(ctx)
  ctx.subscribe("document:changed", function(name, payload)
    -- обработка изменений документа
  end)
end

Нажмите кнопку AI в тулбаре, чтобы открыть ассистента.
