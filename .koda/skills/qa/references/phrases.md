# Штампы: что вырезать

## Вводные и подпорки

| Убрать | Почему |
|---|---|
| «Важно отметить, что…» | Если важно — видно по содержанию |
| «Стоит подчеркнуть» | То же |
| «Нельзя не заметить» | То же |
| «Хочу обратить внимание» | Обращает, а не сообщает |
| «Фактически», «по сути», «по сути дела» | Не меняют смысл |
| «В целом», «в принципе», «в целом можно сказать» | Размывают утверждение |
| «Достаточно сказать, что…» | Лучше сразу сказать |
| «Имеет место быть», «наблюдается ситуация, когда» | Канцелярит |
| «На данный момент», «в текущей реализации» | «Сейчас» или ничего |
| «В рамках задачи», «в части», «по мере возможности» | Канцелярит |
| «Является» | → «это» или перестроить |
| «Осуществляет» (рендер, сортику) | → глагол: «рендерит», «сортирует» |

## Глагольные цепочки (номинализации)

| Убрать | Оставить |
|---|---|
| «выполняет сортировку» | «сортирует» |
| «производит запись файла» | «пишет файл» |
| «осуществляет вызов команды» | «вызывает команду» |
| «обеспечивает поддержку таблиц» | «поддерживает таблицы» |
| «принимает решение об использовании» | «использует» |

## Наречия и усилители

Убирай все: «очень», «достаточно», «довольно», «полностью», «реально», «действительно»,
«быстро», «надёжно», «легко», «просто», «конечно», «разумеется», «безусловно».
«Работает быстро» → назови замер. «Надёжно хранит» → назови механизм.

## Ленивые тотализаторы

«Всегда», «никогда», «любой», «всё», «каждый», «полностью» — без проверки не пиши.
«Ошибки возникают всегда» → «ошибка возникает при не-UTF-8 входе (`lib.rs:88`)».

## Вежливость и хвастовство в UI

- «Пожалуйста, выберите…» → «Выбери…» или просто подпись поля.
- «Отличная работа!» / «Готово! Всё получилось» → убрать.
- «Происходит обработка вашего запроса…» → индикатор прогресса, без текста-объяснения.
