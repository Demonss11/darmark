# Заметки о darmark

Лёгкий редактор Markdown в духе Notepad++: слева исходник,
справа — HTML-предпросмотр, один фиолетовый акцент и никакого
лишнего хрома. Абзац намеренно длинный: по нему оценивают
читаемость кириллицы и ритм строки.

## Возможности

- **Жирный** текст и *курсив* в одном абзаце
- Инлайн-код: `npm run build`

### Горячие клавиши

1. `Ctrl+S` — сохранить документ
2. `Ctrl+I` — инспектор блоков

> Рендер Markdown выполняется на стороне Rust,
> фронтенд лишь присваивает `preview.innerHTML`.

```rust
fn main() {
    println!("Привет, darmark!");
}
```

Подробнее — в [документации](https://darmark.local/docs).

Что поправлено против черновика брифа и почему:

  • --green: #0a8a5f → #046c4e — 4,14:1 (FAIL). Новое значение держит ≥ 4,97:1 даже на самой тёмной светлой поверхности --bg-3.
  • --accent-2: #2563eb → #1d4ed8 — 4,58:1 на --bg-1 и 3,99:1 на --bg-3. Новое — ≥ 5,17:1 везде, ссылки в предпросмотре читаются.
  • --amber: #b45309 → #92400e — 4,45:1 на --bg-1 (панель статуса). Новое — 5,47:1 даже на --bg-3.
  • --red: #dc2626 → #b91c1c — 4,28:1 на --bg-1. Новое — ≥ 4,99:1 везде.
  • --disabled: #6b7280 → #5f6575 — 4,28:1 на --bg-1. Новое — ≥ 4,50:1. Побочный эффект: визуально ближе к --fg-mute (см. открытые вопросы).
  • --accent: #6a5ae0 → #6353dd — 4,48:1 на --bg-1. Оттенок сохранён, насыщенность поднята минимально.
  • --on-error/--on-warning: в светлой теме тёмный текст → белый, потому что заливки стали тёмными (иначе 2,3:1 и хуже).
Открытый вопрос по --gutter в светлой теме. В брифе сказано «--gutter светлее --bg-0», но --bg-0 #f8f9fb уже почти белый, и «светлее» дало бы #ffffff — визуально это не gutter, а инверсия роли. Здесь взято --gutter #eceef2 (чуть темнее рабочей области, 5,32:1 для номеров строк). Нужно решение дизайнера перед хендоффом.
