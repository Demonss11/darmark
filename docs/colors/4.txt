

## Цветовая схема приложения

### Архитектура слоёв

Цветовая схема построена на **HSL-токенах** в CSS-переменных и организована в три уровня:

1. **`core/ui-kit/index.css`** — базовая палитра токенов (zinc, статусные цвета, акцентная палитра)
2. **`core/styles/vars.css`** — прикладные переменные (z-index, размеры, цвета выделения, иконок)
3. **`core/styles/themes.css`** — стили для property-карточек (background/border/text по типам)

---

### 1. Фундамент — Zinc Palette (`core/ui-kit/index.css`)

Вся палитра построена на **Zinc** (нейтральные серые из Tailwind). Это монохромная основа, где светлые элементы — светлее, тёмные — темнее.

| Уровень | Light (L) | Dark (L) |
|---------|-----------|----------|
| zinc-50 | `98%` | — |
| zinc-100 | `96%` | — |
| zinc-200 | `90%` | — |
| zinc-400 | `65%` | — |
| zinc-500 | `46%` | — |
| zinc-700 | `26%` | `200%` |
| zinc-800 | `16%` | `200%` |
| zinc-900 | `10%` | — |
| zinc-950 | `4%` | — |

> **Light:** `primary-bg = 0 0% 97%` (почти белый), `secondary-bg = 0 0% 100%` (чистый белый)
> **Dark:** `primary-bg = 240 6% 10%` (zinc-900), `secondary-bg = 0 0% 7%` (почти чёрный)

### 3. Статусные цвета

| Статус | Light | Dark |
|--------|-------|------|
| **Error** | `red-700` (text/bg) | `red-500` (fg), `red-950` (bg) |
| **Warning** | `amber-700` | `amber-500` (fg), `yellow-950` (bg) |
| **Success** | `green-700` | `green-500` (fg), `green-950` (bg) |
| **Info** | `sky-700` | `sky-500` (fg), `sky-950` (bg) |
| **Purple** | `purple-700` | `purple-500` |
| **Default** | `zinc-900` / `zinc-50` | `zinc-50` / `zinc-900` |

Каждый статус имеет полные уровни: `bg`, `bg-hover`, `primary-bg`, `primary-border`, `secondary-border`, `fg`, `hover`.

---

### 4. Акцентная палитра (24 цвета)

Распределяются по **light/dark** через насыщенность и lightness, сохраняя hue.

| Токен | Hue | Light (S/L) | Dark (S/L) |
|-------|-----|-------------|------------|
| `--peony` | 340° | `100% 91%` | `35% 47%` |
| `--honey` | 44° | `98% 82%` | `35% 35%` |
| `--mint` | 120° | `71% 85%` | `34% 34%` |
| `--turquoise` | 194° | `100% 80%` | `35% 37%` |
| `--lavender` | 247° | `100% 92%` | `35% 53%` |
| ...и ещё 19 цветов | | | |

**Иконочные варианты** — те же цвета, но с `l ≈ 35%` (light) / `l ≈ 65%` (dark):
- `--color-icon-yellow` → от `--honey`, l=35%/65%
- `--color-icon-green` → от `--mint`, l=35%/65%
- и т.д.

### 6. Property-карточки (`themes.css`)

30 типов карточек (red, blue, green, purple, teal, orange и т.д.) — каждая имеет 3 набора: **bg / border / text**.

Light (пример, red):
- bg: `#fecaca`, border: `#fca5a5`, text: `#991b1b`

Dark (пример, red):
- bg: `#991b1b`, border: `#b91c1c`, text: `#fecaca`

---

| `--alpha-90` | `90%` | — |
| `--alpha-high-03` | — | `3%` |
| `--alpha-high-10` | — | `10%` |
| ... | | |

---

### 8. Glass-эффекты (тени)

4 уровня стеклянных теней для light/dark:
- `--shadow-glass-sm` — лёгкий
- `--shadow-glass-md` — средний
- `--shadow-glass-lg` — большой
- `--shadow-glass-xl` — максимальный (используется в Tailwind: `shadow-glass-xl`)

### Итоговая схема слоёв

```
core/ui-kit/index.css   ← БАЗОВЫЙ СЛОЙ
  ├─ Zinc palette (10 уровней)
  ├─ Primary/Secondary/Tertiary токены
  ├─ Inverse-палитра
  ├─ Статусные палитры (error/warning/success/info/purple/default)
  ├─ Alpha-слои (03–90)
  ├─ Акцентная палитра (24 цвета: peony→velvet)
  └─ Chart-палитра (5 цветов)

core/styles/vars.css    ← СЛОЙ ПРИКЛАДНЫХ ПЕРЕМЕННЫХ
  ├─ Цвета выделения (highlight: honey/mint/lavender/turquoise)
  ├─ Иконочные цвета (darker/lighter от акцентов)
  ├─ UI-константы (z-index, размеры, тени)
  ├─ Статусы версии (new/modified/deleted/rename)
  ├─ Diff-цвета (added/removed)
  ├─ Search-подсветка
  └─ Input/tooltip/cmd/kbd цвета

core/styles/themes.css  ← СЛОЙ СВОЙСТВЕННЫХ КАРТОЧЕК
  └─ 30 property-карточек (bg/border/text × light/dark)

```
