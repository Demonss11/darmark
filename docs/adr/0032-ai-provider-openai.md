# ADR-0032. Провайдер LLM в MVP — OpenAI-совместимый API (routerai.ru); локальная LLM (Ollama) отложена (вне scope)

> Имя файла сохранено ради ссылок и означает **протокол** (OpenAI-совместимый Chat Completions),
> а не вендора: точка доступа в MVP — роутер **`routerai.ru`** (§2.1).

> **Обобщено ADR-0035** (12.10.2026): одиночный провайдер → пользовательский map в `config.json`.
> Протокол, секрет/сеть/согласие, выбор клиента (ADR-0033) и размещение рантайма (ADR-0034) —
> сохраняются. «Единственный провайдер» читать как «провайдер по умолчанию».

- **Статус:** **Принят**
- **Дата:** 11.10.2026
- **Основание:** продуктовое решение 11.10.2026 (пересмотр открытого вопроса №1 IDEA-013 и
  проектирования провайдера в ТЗ AI-ассистента, Ф1/Ф2 реализованы);
  `docs/adr/0030-bottom-dock-two-modes.md`; прототип режима AI (удалён после реализации)
- **Связанные:** `docs/DESIGN_DOC.md`; `docs/adr/0030-bottom-dock-two-modes.md` (режим AI);
  `docs/adr/0033-ai-http-client-streaming.md` (HTTP-клиент/стриминг);

## 1. Контекст

### 1.1. Проблема

AI-ассистенту нужен **провайдер LLM**. Это единственная часть AI, требующая сетевой доступ,
а сеть в продукте ограничена жёстко.

### 1.2. Что уже зафиксировано (не пересматривается)

- **CSP `default-src 'self'`** → сеть только с Rust-стороны (`DESIGN_DOC` §11; ADR-0030 §2.3).
- **Приватность:** содержимое не покидает машину без согласия (ADR-0030 §2.4).
- **Рендер — через Rust-санитайзер** (ADR-0030 §2.2 п. 16).
- **AI — не плагин** (ADR-0021).
- **D6 ≤6 МБ:** AI-клиент — малая часть бюджета.

### 1.3. Почему решение пересматривается

ТЗ проектировало **гибрид**: локальная модель (Ollama) по умолчанию, облачный API — расширение.
Продуктовое решение 11.10.2026 пересматривает это: локальная LLM требует внешнего сервера,
медленная на CPU, усложняет онбординг; выгода приватности перекрыта согласием.

Локальный провайдер **не реализуется сейчас** (вне scope; при возврате — отдельный ADR).

---

## 2. Решение

**В MVP единственный реализуемый провайдер LLM — OpenAI-совместимый API (сторонний роутер
`routerai.ru`). Локальная LLM (Ollama) и гибрид — вне scope. Сетевой слой — Rust
(`src-tauri/src/ai/`); интерфейс провайдера держим расширяемым, но реализуется только
OpenAI-совместимый провайдер.**

### 2.1. Провайдер и протокол

1. Провайдер — **OpenAI-совместимый API** (сторонний роутер, **не** `api.openai.com`): базовый URL
   `https://routerai.ru/api/v1`, авторизация — **Bearer-токен**. Клиент может быть любым
   OpenAI-совместимым; выбор Rust-клиента — ADR-0033.
2. Модель по умолчанию — **`deepseek/deepseek-v4.1-flash`**; `base_url` и `model`
   **конфигурируемы**. Прочие параметры (`max_tokens`, `temperature`) — тоже (значения по
   умолчанию — открытый вопрос PM).
3. Сетевой слой — **Rust** (`crates/app/src-tauri/src/ai/`). В TS-слое сетевых вызовов нет (CSP).

### 2.2. Расширяемость интерфейса провайдера

4. Провайдер за абстракцией (trait/`enum`), допускающей добавление провайдеров **без ломки
   контрактов** IPC и замороженных контрактов §13.2. В MVP вариант ровно один —
   OpenAI-совместимый (`routerai.ru`); прочие (Anthropic, локальный) — возможное расширение позже.

### 2.3. Согласие (обязательно)

6. **Согласие обязательно.** Содержимое документа уходит в **облако** → перед **первой** отправкой
   показывается **диалог согласия** (модальный, транзиентный; ADR-0030 §2.4).
7. Формулировка согласия — явно про **облачный сервис `routerai.ru`** (сторонний роутер; данные
   покидают машину и уходят в его облако). Пользователь может **не разрешать**; без согласия
   запросы **не уходят** (ошибка в чате, не отправка). Область согласия покрывает и отправку
   исходников **установленного** плагина (`plugin.json` + entry), которую инициирует ассистент
   по промту отладки через MCP-инструмент `plugin_read`: отдельная формулировка в UI не
   вводится (ADR-0035 §2.7).

### 2.4. Секреты

8. API-ключ **хранится локально** в каталоге `%APPDATA%/darmark/` через **существующий
   settings-store (D11)**: файл `config.json`, секция `ai`. Ключ **не логируется**.
9. **Windows Credential Manager / DPAPI отклонены** (11.10.2026) как избыточные для локального лёгкого
   редактора (§4). Trade-off: секрет лежит на диске **в открытом виде**; митигации — **маскирование
   в UI**, **запрет логирования**, **права каталога** `%APPDATA%/darmark/`.

### 2.5. Сеть и TLS

11. Сеть — **только Rust-сторона**; **TLS — системный SChannel** (без OpenSSL); HTTP-клиент —
    **`reqwest`** + **SSE** (ADR-0033).
12. **Таймаут** ~30 с; клиентский **rate limit** ~1 запрос/с.
13. **Маппинг ошибок** — устойчивый, с ключевыми кейсами: `401` — ключ; `429` — лимит
    (учитывать `Retry-After`); `5xx` — ретрай с backoff. Неизвестный код → общее сообщение.
14. **Логирование — только метаданные**; содержимое не логируется.

### 2.6. Стоимость и лимиты

15. Контроль стоимости: `max_tokens`, выбор модели, показ токенов (`usage`).
16. При недоступности роутера — **понятная ошибка** с действием **«Повторить»**.
    **Fallback отсутствует** (§4): резервная модель/точка доступа не вводится.

### 2.7. Бюджет D6

17. **AI-клиент — ориентир ≤1.0 МБ** (пересмотрен с ≤0.5 МБ по F55; ADR-0033). Общий gate
    ≤6 МБ не меняется.

### 2.8. Принцип баланса MVP

19. AI-ассистент — **дополнительный** функционал лёгкого редактора. MVP **не перенагружаем**.
    Зафиксировано 11.10.2026:
    - **скиллов ровно 2** — «Объяснить файл» и «Создать плагин»;
    - **история чата — в памяти на сессию** (не персистится);
    - **телеметрия — вне MVP**;
    - **диффы — на Rust-стороне** (в TS не вычисляются);
    - **формат скиллов — JSON**.

### 2.9. Открытые вопросы

20. **Закрыты 11.10.2026:** модель по умолчанию (`deepseek/deepseek-v4.1-flash`, §2.1 п. 2);
    хранилище ключа (`config.json`, секция `ai`; §2.4); поведение при недоступности роутера (ошибка +
    «Повторить», без fallback; §2.6 п. 16); **выбор HTTP-клиента и стриминга** — **ADR-0033**.
    Остаётся открытым:
    - значения по умолчанию `max_tokens`/`temperature` (§2.1 п. 2);
    - **включение стриминга** в MVP или Фазу 3 (механизм SSE зафиксирован в ADR-0033; факт — за PM).

## 3. Последствия

**Положительные:**

- **Ассистент работает «из коробки»** — без установки сервера и загрузки моделей.
- **Сеть остаётся в одной точке** (Rust), CSP не ослабляется.
- **Расширяемость без ломки контрактов:** интерфейс провайдера допускает Anthropic/локальный позже.
- **Явная модель согласия и отказ** — отправка управляема пользователем.

**Отрицательные / ограничения:**

- **Данные уходят в облако стороннего роутера** — путь: **darmark → `routerai.ru` → модель**;
  приватность опирается на **явное согласие** и **отсутствие логирования содержимого**.
- **Зависимость от роутера** — доступность, лимиты, стоимость вне нашего контроля;
  **fallback нет** — только ошибка + **«Повторить»** (§2.6).
- **Секреты** — ключ на диске **в открытом виде**; митигации — маскирование в UI,
  запрет логирования, права каталога (§2.4).
- **D6 под наблюдением** — ориентир AI-клиента **≤1.0 МБ** (ADR-0033).

### 3.3. Влияние и трассировка

- **ТЗ:** ТЗ AI-ассистента (Ф1/Ф2); перспектива Ф3 — `tasks/TZ-AI-PHASE3.md`.
- **ADR-0030:** режим AI дока и диалог согласия.
- **ADR-0021:** AI — не плагин (нужен Rust-сетевой слой).
- **ADR-0027 §2.4:** события AI — аддитивны, мажор `HOST_API_VERSION` не поднимается.

**Обратимость:** провайдер за абстракцией + отдельный модуль `src-tauri/src/ai/`; добавление
иного провайдера — без правок замороженных контрактов §13.2. Смена `base_url`/`model` не меняет
код клиента (OpenAI-совместимый протокол). Отказ от облачного провайдера потребует нового ADR.

## 4. Отклонённые альтернативы

- **Локальная LLM (Ollama).** **Отложена на неопределённый срок** (вне scope): внешний сервер +
  большие модели (онбординг), медленная CPU-генерация, дублирование согласия ради приватности.
  При возврате — отдельный ADR.
- **Гибрид (локальный + облачный).** Отклонён **сейчас**: локальной реализации нет, усложняет UI.
- **Прямой `api.openai.com`.** Отклонён в пользу `routerai.ru` (тот же протокол, роутинг и доступ к модели).
- **Anthropic API.** Отклонён как MVP-провайдер; возможно **расширение** позже за той же абстракцией.
- **AI как плагин.** Отклонён: плагину недоступны сеть и Rust-сетевой слой (ADR-0021).
- **Сетевые вызовы из TS.** Отклонён: нарушает CSP и инвариант «сеть — на Rust-стороне».
- **Windows Credential Manager / DPAPI.** **Отклонены** (11.10.2026): избыточны для лёгкого редактора.
  Выбрано: **`config.json` (секция `ai`)** через settings-store D11 (§2.4).
- **Fallback при недоступности роутера.** **Отклонён** (11.10.2026): только ошибка + **«Повторить»** (§2.6).
- **HTTP-клиент с OpenSSL.** Отклонён: выбран **системный SChannel** (ADR-0033).
