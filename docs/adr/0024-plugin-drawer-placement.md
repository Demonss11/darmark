# ADR-0024. Размещение управления плагинами: триггер в тулбаре + правый дровер (вариант C)

- **Статус:** **Принят**
- **Дата:** 10.10.2026
- **Основание:** прототип `ideas/front_plugins-drawer-c.html` (C-v2); прототип размещения
  `ideas/front_plugins-placement.html`; `docs/adr/0021-*`, `docs/adr/0023-*`;
  `tasks/TZ-UX-SPEC-CLEANUP.md` §1, §9
- **Связанные:** `docs/DESIGN_DOC.md` §5.5, §13.2, §16; `crates/app/src/main.ts`, `shell.ts`, `dialog.ts`
  (переиспользование примитивов), `drawer.ts` (замена `sidebar.ts`)

---

## 1. Контекст

После удаления `panel-explorer` левый край окна занимают только `nav.rail` (44px) и `aside#sidebar`
(224px) под панель плагинов. Итого 268px хрома слева от редактора, а карточки плагинов обрезаны:
224px не хватает на монограмму, имя, версию, статус и тумблер в одну строку, инфо-поповер
прижимается к краю.

Цель — **чистый левый край** (редактор получает +268px), **нормальная ширина карточек**
(440px против текущих 224px) и **не слабее варианта A** (текущего состояния): сохранить
идентичность плагина, состояния, плотность карточек и доступность (§1 и §9
`TZ-UX-SPEC-CLEANUP.md`).

---

## 2. Решение

Управление плагинами переезжает из левого sidebar в **правый модальный дровер**; триггер —
в верхний тулбар рядом с палитрой. Левые `rail` и `sidebar` упраздняются, `sidebar.ts` удаляется
целиком (заменяется контроллером `drawer.ts`).

### 2.1. Зафиксированные решения

| # | Вопрос | Решение |
|---|--------|---------|
| 1 | Модальность | **Модальный:** `role="dialog"`, `aria-modal="true"`; `inert` на `#app`; backdrop закрывает; focus-trap; возврат фокуса на `#tb-plugins` |
| 2 | Ширина | `--w-drawer: 440px` (на узком окне ≤900px — 100vw) |
| 3 | Журнал | `#rail-logs` → точка входа в статусбар `#sb-logs` + бейдж `#log-badge`; полноценная панель журнала — H3, вне scope |
| 4 | Судьба `#side-count` | **Сохранить** замороженный id (переезжает в `.drawer-head`); e2e читает его без миграции шага счётчика |
| 5 | Судьба `#plugin-manager` | **Сохранить**, переместить в `#drawer-body` (перемещение, не второй экземпляр) |

### 2.2. Реализация модальности

Дровер — **постоянный DOM** (`#drawer` + `#backdrop` как прямые дети `body`), а не транзитный
оверлей `openDialog()`. Причина: `#plugin-manager` и `#side-count` обязаны существовать
постоянно — состояние раскрытия карточек (`Set<string>` в замыкании `createPluginManager`)
и счётчик живут вне DOM, а `openDialog` создаёт и удаляет DOM на каждый показ. Из `dialog.ts`
переиспользуются **примитивы** (feature-detect `inert`, логика focus-trap), не `openDialog`.

Модальный слой: `inert` на `#app`, пока дровер открыт; `#backdrop` и `#drawer` размещаются
вне `#app`, чтобы `inert` палитры не глушил сам дровер. Закрытие: `Esc`, клик по `#backdrop`,
кнопка `#drawer-close`. e2e проверяет класс `.open` на `#drawer`, не `getComputedStyle`
(`transform`/`transition` не проверяются).

### 2.3. Взаимоисключение с палитрой

Ctrl+K (палитра) и дровер взаимоисключены: открытие одного закрывает другой — не два модальных
слоя одновременно.

### 2.4. Точки композиции (`main.ts`)

1. `createDrawer({ root, trigger, closeButton, backdrop, title })` — контейнер.
2. `createPluginManager({ root: drawer.content, … })` — содержимое (шов: менеджер не знает о дровере).
3. `createPluginStatusBar({ …, onShowPanel: () => drawer.open() })`.
4. `createShell({ …, drawer })` — привязка `#tb-plugins` → `drawer.toggle()`.

## 3. Последствия

**Положительные:**
- Левый край чистый: редактор получает +268px ширины.
- Карточки плагинов получают 440px вместо 224px: монограмма, имя, версия, статус и тумблер
  в одну строку; инфо-поповер не обрезается краем.

**Цена / ограничения:**
- Миграция замороженных контрактов: `#rail-plugins`, `#panel-plugins`, `#rail-logs` удаляются
  (атомарная миграция кода + e2e в одном коммите: `plugins.steps.js`, `a11y.feature`,
  `plugin-panel.feature`).
- Тулбар плотнее: триггер icon-only (≈28×28), проверка на ширине 1280px.
- Дровер модальный: фон перекрыт backdrop, `inert` на `#app` — повторный клик по триггеру
  недоступен, пока дровер открыт (нормально для модалки).
- «Журнал» — только точка входа в статусбаре; полноценная панель журнала отложена (H3).

**Обратимость:** все изменения в одном коммите → `git revert`; `drawer.ts` можно оставить,
скрыв триггер `#tb-plugins`.

---

## 4. Отклонённые альтернативы

- **A — оставить sidebar как есть.** Отклонён: левый край занят 268px хрома, карточки в 224px
  обрезаны; цель ADR (чистый левый край + ширина карточек) не достигнута.
- **B — кнопка рядом, панель слева.** Отклонён: не освобождает левый край (панель остаётся
  слева), не даёт редактору +268px.
- **IDEA-005 — компактный триггер + попап.** Отложен: попап не даёт 440px карточкам, состояния
  раскрытия и согласия на permissions теснее; при выборе C не требуется.
