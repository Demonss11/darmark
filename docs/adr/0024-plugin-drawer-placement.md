# ADR-0024. Размещение управления плагинами: триггер в тулбаре + правый дровер (вариант C)

- **Статус:** **Принят**
- **Дата:** 10.10.2026
- **Основание:** прототипы размещения дровера (C-v2) — удалены после реализации;
  `docs/adr/0021-*`, `docs/adr/0023-*`;
  `docs/DESIGN_DOC.md` §13.2
- **Связанные:** `docs/DESIGN_DOC.md` §5.5, §13.2; `crates/app/src/main.ts`, `shell.ts`, `dialog.ts`
  (переиспользование примитивов), `drawer.ts` (замена `sidebar.ts`)

---

## 1. Контекст

После удаления `panel-explorer` левый край окна занимают `nav.rail` и `aside#sidebar` под панель
плагинов — этого не хватает на карточки: они обрезаны по ширине.

Цель — **чистый левый край**, **нормальная ширина карточек** (440px) и **не слабее варианта A**
(текущего состояния): сохранить идентичность плагина, состояния, плотность карточек и доступность
(§13.2 `DESIGN_DOC`).

---

## 2. Решение

Управление плагинами переезжает из левого sidebar в **правый модальный дровер**; триггер —
в верхний тулбар рядом с палитрой. Левые `rail` и `sidebar` упраздняются, `sidebar.ts` удаляется
целиком (заменяется контроллером `drawer.ts`).

### 2.1. Зафиксированные решения

| # | Вопрос | Решение |
|---|--------|---------|
| 1 | Модальность | **Модальный:** backdrop закрывает, focus-trap, возврат фокуса на триггер |
| 2 | Ширина | `440px` (на узком окне — 100vw) |
| 3 | Журнал | точка входа в статусбар + бейдж; слот наполняется панель-консолью (ADR-0029); полноценная панель журнала — H3, вне scope |
| 4 | Судьба `#side-count` | **Сохранить** замороженный id (переезжает в дровер) |
| 5 | Судьба `#plugin-manager` | **Сохранить**, переместить в дровер (перемещение, не второй экземпляр) |

### 2.2. Реализация модальности

Дровер — **постоянный DOM**, а не транзитный оверлей `openDialog()`. Причина: `#plugin-manager`
и `#side-count` обязаны существовать постоянно — состояние раскрытия карточек и счётчик живут
вне DOM, а `openDialog` создаёт и удаляет DOM на каждый показ. Из `dialog.ts` переиспользуются
**примитивы** (feature-detect `inert`, логика focus-trap), не `openDialog`.

Модальный слой: `inert` на `#app`, пока дровер открыт; `#backdrop` и `#drawer` — вне `#app`.
Закрытие: `Esc`, клик по `#backdrop`, кнопка `#drawer-close`.

### 2.3. Взаимоисключение с палитрой

Ctrl+K (палитра) и дровер взаимоисключены: открытие одного закрывает другой — не два модальных
слоя одновременно.

### 2.4. Точки композиции (`main.ts`)

1. Дровер (контейнер).
2. Менеджер плагинов (содержимое).
3. Статусбар (точка входа в журнал).
4. Шелл (привязка триггера к дроверу).

---

## 3. Последствия

**Положительные:**
- Левый край чистый: редактор получает дополнительную ширину.
- Карточки плагинов получают 440px — достаточно на монограмму, имя, версию, статус и тумблер.

**Цена / ограничения:**
- Миграция замороженных контрактов: `#rail-plugins`, `#panel-plugins`, `#rail-logs` удаляются
  (атомарная миграция кода + e2e в одном коммите).
- Тулбар плотнее: триггер icon-only, проверка на ширине 1280px.
- Дровер модальный: повторный клик по триггеру недоступен, пока дровер открыт (нормально для модалки).

**Обратимость:** все изменения в одном коммите → `git revert`; `drawer.ts` можно оставить,
скрыв триггер `#tb-plugins`.

---

## 4. Отклонённые альтернативы

- **A — оставить sidebar как есть.** Отклонён: не решает цель ADR (чистый левый край + ширина карточек).
- **B — кнопка рядом, панель слева.** Отклонён: не освобождает левый край.
- **IDEA-005 — компактный триггер + попап.** Отложен: не даёт 440px карточкам; при выборе C не требуется.
