# ADR-0037. Светлая тема (ручной тумблер) и ролевые гарнитуры

- **Статус:** **Предложен**
- **Дата:** 13.10.2026
- **Основание:** направление A — «ролевые гарнитуры +
  светлая тема»); `docs/adr/0025-*` (пересмотр нормы «одна тёмная тема»); `DESIGN.md` § Colors /
  § Typography; `docs/DESIGN_DOC.md` §5, §13.2
- **Связанные:** `docs/adr/0025-*` (частично заменён настоящим ADR), `DESIGN.md` (Colors,
  Typography, Do's/Don'ts), `docs/DESIGN_DOC.md` §5, §13.2

---

## 1. Контекст

ADR-0025 отклонил светлую тему (норма «одна тёмная»). Продуктовая потребность: нужен выбор,
тёмная остаётся по умолчанию, светлая вводится как **ручной тумблер** без привязки к системной теме.

Типографика расширяется до 4 ролевых гарнитур (§2.3). Акцент остаётся фиолетовым.

**Ограничения:** общие проектные (CSP `default-src 'self'`, база ≤ 6 МБ — D6) + E2E-контракты §13.2 не должны ломаться.

---

## 2. Решение

### 2.1. Ручной тумблер тем

Вводится ручной переключатель Dark/Light (`data-theme="dark|light"` на `<html>`):

- **Тёмная тема — по умолчанию** (`data-theme="dark"`), сохранение выбора между сессиями.
- **`prefers-color-scheme` не используется** — тема управляется только пользователем.
- Переключатель — в тулбаре или статусбаре (конкретное место фиксируется при реализации;
  e2e-контракт на переключатель аддитивен к §13.2).
- `color-scheme` на `<html>` переключается вместе с темой (нативные контролы/скроллбары).

### 2.2. Светлая палитра

Слои разведены, все текстовые пары ≥ 4.5:1 (WCAG AA), сохранён «холодный» подтон.
Токены — см. `DESIGN.md` § Colors → Светлая тема.

Акцент и статусы сохраняются из тёмной темы (контраст обеспечен либо докруткой).

### 2.3. Ролевые гарнитуры (4 роли)

UI (системный стек), Editor (JetBrains Mono), Body (Inter), Headings (Source Serif 4).
Доставка — встроенные `.woff2`, OFL 1.1 (`DESIGN.md` § Typography).

### 2.4. Закрытые дизайн-решения

1. **`--disabled` — только точки/иконки, НЕ цвет текста.** Текст статуса «выкл» → `--fg-mute`.
2. **Плотность предпросмотра — компактная** (13px, межстрочный 1.7, ограничение ширины).
3. **`--gutter` в светлой теме — темнее рабочей области.**
4. **Вкладки — по паттерну WAI-ARIA tabs** (атрибуты, roving tabindex, навигация ←/→/Home/End, Ctrl+W).
5. **Лигатуры:** редактор/код — только `liga`; предпросмотр — `liga` + `calt`.
6. **Заголовки предпросмотра:** убывающая шкала кеглей (3 уровня), вес 700, границы у h1/h2.

## 4. Отклонённые альтернативы

- **Системная тема (`prefers-color-scheme`).** Отклонено: только ручной выбор.
- **CDN-шрифты.** Отклонено (CSP, внешняя зависимость).
- **`--disabled` на тексте.** Отклонено (текст читается как статус).

---

## 5. Последствия

**Положительные:** пользователь получает выбор темы; светлая палитра закрывает сценарий «работа при ярком свете».

**Отрицательные / цена:**
- **Пересмотр ADR-0025:** норма «одна тёмная тема» заменяется на «тёмная по умолчанию + ручной тумблер». ADR-0025 помечается как **частично заменён ADR-0037**.
- Цена: два набора токенов, +200–400 КБ к базе, обновление E2E-фикстур (аддитивно).
- `DESIGN.md` требует правки: снятие Don't «вводить вторую тема», разделы Colors/Typography.
