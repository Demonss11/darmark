# ADR-0037. Светлая тема (ручной тумблер) и ролевые гарнитуры

- **Статус:** **Предложен**
- **Дата:** 13.10.2026
- **Основание:** направление A — «ролевые гарнитуры +
  светлая тема»); `docs/adr/0025-*` (пересмотр нормы «одна тёмная тема»); `DESIGN.md` § Colors /
  § Typography; `docs/DESIGN_DOC.md` §5, §13.2
- **Связанные:** `docs/adr/0025-*` (частично заменён настоящим ADR), `DESIGN.md` (Colors,
  Typography, Do's/Don'ts), `docs/DESIGN_DOC.md` §5, §13.2

---

## 1. Контекст

ADR-0025 зафиксировал норму «одна тёмная тема — замороженный контракт» и отклонил введение
светлой темы. Продуктовая потребность показала,
что пользователю нужен выбор: тёмная тема остаётся по умолчанию (норма для инструмента),
но светлая тема вводится как **ручной тумблер** без привязки к системной теме.

Параллельно типографика из двух ролей (UI + моноширинная) расширяется до **четырёх ролевых
гарнитур**: оболочка (системный стек), редактор/код/gutter (JetBrains Mono — уже в дереве),
тело предпросмотра (Inter), заголовки предпросмотра (Source Serif 4 — засечки). Акцент
остаётся фиолетовым (не зелёным/синим).

**Ограничения:**
- CSP `default-src 'self'` — шрифты только same-origin `.woff2`, без CDN и без правок CSP.
- Лицензия OFL 1.1 — встроенные шрифты распространяются с приложением, текст лицензии
  включается в дистрибутив.
- База ≤ 6 МБ (D6) — суммарный размер `.woff2` (4 гарнитуры, веса 400/700) должен уложиться
  в бюджет; при превышении — только подмножество глифов (subset) по согласованию.
- `data-theme` на `<html>`, выбор сохраняется между сессиями (`localStorage`/`config.json`).
- E2E-контракты §13.2 (DOM id, селекторы, тексты) не должны ломаться.

---

## 2. Решение

### 2.1. Ручной тумблер тем

Вводится ручной переключатель Dark/Light (`data-theme="dark|light"` на `<html>`):

- **Тёмная тема — по умолчанию** (`data-theme="dark"`), сохранение выбора между сессиями.
- **`prefers-color-scheme` не используется** — тема управляется только пользователем.
- Переключатель — в тулбаре или статусбаре (конкретное место фиксируется при реализации;
  e2e-контракт на переключатель аддитивен к §13.2).
- `color-scheme` на `<html>` переключается вместе с темой (нативные контролы/скроллбары).

### 2.2. Светлая палитра

Слои разведены, все текстовые пары ≥ 4.5:1 (WCAG AA), сохранён «холодный» подтон:

| Токен | Значение | Роль |
|-------|----------|------|
| `--bg-0` | `#fafbfc` | базовый фон приложения |
| `--bg-1` | `#f0f2f6` | панели, тулбар, вкладки |
| `--bg-2` | `#e3e7ee` | карточки, строки списков |
| `--bg-3` | `#d4d9e3` | hover-состояния, кнопки |
| `--line` | `#b8bfcc` | границы, разделители |
| `--line-soft` | `#d0d5e0` | тонкие границы, подложки |
| `--gutter` | `#d8dde6` | фон колонки номеров строк (темнее рабочей области) |

Текст в светлой теме (значения контрастны на `--bg-0..--bg-3`):

| Токен | Значение | Роль |
|-------|----------|------|
| `--fg` | `#1a1d24` | основной текст |
| `--fg-dim` | `#4a5068` | вторичный текст |
| `--fg-mute` | `#6b7194` | третий уровень, статус «выкл» |

Акцент и статусы сохраняются из тёмной темы (фиолетовый `--accent`, `--green`, `--amber`,
`--red`, `--teal`) — они уже контрастны на светлых фонах либо докручиваются по светлоте.

### 2.3. Ролевые гарнитуры (4 роли)

| Роль | Гарнитура | Доставка | Лицензия |
|------|-----------|---------|----------|
| Оболочка (UI) | Системный стек: Segoe UI (`-apple-system, "Segoe UI", system-ui, Roboto, Arial, sans-serif`) | ОС, без файлов | — |
| Редактор/код/gutter | **JetBrains Mono** | Встроенные `.woff2` (уже в дереве: Regular + Bold) | OFL 1.1 |
| Тело предпросмотра | **Inter** | Встроенные `.woff2` (400/700) | OFL 1.1 |
| Заголовки предпросмотра | **Source Serif 4** | Встроенные `.woff2` (400/700) | OFL 1.1 |

**Способ доставки:** same-origin `.woff2` в `crates/app/public/fonts/`, текст лицензии
(`OFL.txt`) включается в дистрибутив. **Без CDN, без правок CSP** (`default-src 'self'` уже
покрывает).

### 2.4. Закрытые дизайн-решения

1. **`--disabled` — только точки/иконки, НЕ цвет текста.** Текст статуса «выкл» → `--fg-mute`.
   Класс `.sem.off` для точек-индикаторов: цвет фона/границы, не текст.
2. **Плотность предпросмотра — осознанная:** `font-size: 13px`, `line-height: 1.7`,
   `max-width: 860px`.
3. **`--gutter` в светлой теме — темнее рабочей области** (не «светлее»): `#d8dde6` против
   `#fafbfc`.
4. **Вкладки — целевой паттерн WAI-ARIA tabs:** `role="tablist"/"tab"/"tabpanel"`,
   `aria-selected`/`aria-controls`/`aria-labelledby`, roving tabindex, навигация ←/→/Home/End,
   Ctrl+W для закрытия.
5. **Лигатуры:** в редакторе/коде — `font-feature-settings: "liga" 1, "calt" 0`;
   в предпросмотре — `calt` включён.
6. **Кегли заголовков предпросмотра (Source Serif 4):**

   | Элемент | Кегль | line-height | Вес | Граница |
   |----------|-------|------------|-----|---------|
   | h1 | 30px | 1.22 | 700 | `border-bottom: 1px solid var(--line)` |
   | h2 | 21px | 1.30 | 700 | `border-bottom: 1px solid var(--line-soft)` |
   | h3 | 17px | 1.32 | 700 | — |

## 3. Обязательные требования

- [ ] `data-theme="dark|light"` на `<html>`; тёмная по умолчанию; выбор сохраняется между сессиями.
- [ ] `prefers-color-scheme` не используется.
- [ ] Светлая палитра из §2.2 определена в `style.css` (отдельный блок `[data-theme="light"]`).
- [ ] Все текстовые пары в обеих темах ≥ 4.5:1 (WCAG AA).
- [ ] `--disabled` применяется только к точкам/иконкам; текст «выкл» — `--fg-mute`.
- [ ] `.sem.off` — цвет точки, не текста.
- [ ] Плотность предпросмотра: 13px / 1.7 / `max-width: 860px`.
- [ ] `--gutter` в светлой теме темнее рабочей области.
- [ ] Вкладки реализованы по WAI-ARIA tabs (атрибуты, roving tabindex, ←/→/Home/End, Ctrl+W).
- [ ] Лигатуры: редактор/код — `liga 1, calt 0`; предпросмотр — `calt` включён.
- [ ] Заголовки предпросмотра: кегли 30/21/17, вес 700, границы у h1 (`--line`) и h2 (`--line-soft`).
- [ ] Inter и Source Serif 4 добавлены в `crates/app/public/fonts/` (Regular + Bold/700),
      `OFL.txt` обновлён/дополнен.
- [ ] Шрифты подключаются через `@font-face` с `src: url("/fonts/...")` (same-origin).
- [ ] CSP не меняется (`default-src 'self'`).
- [ ] E2E-контракты §13.2 не ломадутся (DOM id, селекторы, тексты не меняются).
- [ ] Акцент остаётся фиолетовым (`--accent`), не зелёным/синим.
- [ ] `DESIGN.md` обновлён (Colors, Typography, Do's/Don'ts, Components).
- [ ] `DESIGN_DOC.md` — строка ADR-0037; §5 — при необходимости про токены тем.

## 4. Отклонённые альтернативы

- **`prefers-color-scheme` как источник темы.** Отклонено: тема должна быть под контролем
  пользователя; системная тема не должна неявно менять интерфейс инструмента.
- **Автоопределение темы при первом запуске.** Отклонено: тёмная тема — норма и по умолчанию;
  светлая включается явным действием.
- **CDN/Google Fonts для Inter/Source Serif 4.** Отклонено: нарушает CSP `default-src 'self'`
  и добавляет внешнюю зависимость; только встроенные same-origin `.woff2`.
- **Зелёный/синий акцент.** Отклонено: фиолетовый — закреплённая идентичность продукта
  (`DESIGN.md`, ADR-0024 «Один акцент»).
- **Расширение `--disabled` на текст.** Отклонено: текст «выкл» должен читаться как статус
  второго уровня (`--fg-mute`), а не быть «невидимым»; цвет инвалидности оставлен для
  графики (точки, иконки).

## 5. Последствия

**Положительные:**
- Пользователь получает выбор темы; тёмная остаётся нормой для инструмента.
- Ролевые разделения шрифтов повышают читаемость: заголовки с засечками в предпросмотре
  визуально отделены от текста оболочки.
- WAI-ARIA tabs улучшают доступность вкладок.
- Светлая палитра закрывает сценарий «работа при ярком свете».

**Отрицательные / цена:**
- **Пересмотр ADR-0025:** норма «одна тёмная тема — замороженный контракт» заменяется на
  «тёмная по умолчанию + ручной тумблер». ADR-0025 помечается как **частично заменён
  ADR-0037** (разделы палитры/типографики остаются в силе; норма про одну тему — нет).
- Два набора токенов темы — больше работы по поддержке и визуальной проверке.
- Inter + Source Serif 4 добавляют ≈ 200–400 КБ к базе (в пределах D6, но требует контроля).
- E2E-фикстуры/шаги, читающие цвета, могут потребовать обновления (аддитивно, не ломая §13.2).
- `DESIGN.md` требует правки: снятие Don't «вводить вторую тему», разделы Colors/Typography.
