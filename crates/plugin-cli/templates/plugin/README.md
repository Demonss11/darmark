## Проверка

Запустите из каталога плагина:

```text
darmark-plugin test .
```

## Установка

Скопируйте каталог в `%APPDATA%\darmark\plugins\` — плагин появится в панели «Плагины»
при следующем запуске ПЕНАЛ.

Подробности — `docs/PLUGIN_GUIDE.md` и `docs/PLUGIN_API.md`.
