## Открытые вопросы

### E2E

- **Добавлено и зелёное:** `features/undo.feature` (`Ctrl+Z`/`Ctrl+Y` для ввода и откат программной
  правки плагина `apply_edit`), `features/plugin-back-preview.feature` (S10-D),
  `features/plugin-quarantine.feature` (N=3 + сброс тумблером). S14 подтверждён (release-бинарник).
  Инцидентально починен `e2e/steps/tabs.steps.js` — TS-аннотации в `.js` ломали старт всего прогона.
- **`plugins.feature` — ЗАКРЫТО.** Продуктовый фикс: `PluginViews::sync` чистит контент view при
  отзыве `view:modify` (`clear_content`); при возврате права плагин переиздаёт HTML. Сценарий
  «Повторная выдача прав не обнуляет view по подписке» зелёный.
- **`tabs.feature` — ЗАКРЫТО.** Фича переведена на числительные; изоляция **без навигации**
  (`reload` рвёт WebDriver-сессию): `Before(@tabs)` снимает `dirty` синтетическим `Ctrl+Z` по каждой
  вкладке и закрывает лишние до одной. Standalone-прогон зелёный; сценарий «сохранение» → `@manual`
  (нативный диалог «Сохранить как»).
- **НОВОЕ (инфраструктура, открыто):** полный `npm run test:e2e` **нестабилен** —
  `tauri-driver`/`msedgedriver` отваливается в середине (`ECONNREFUSED` на `127.0.0.1:4444`,
  «Failed to create a session»), далее спеки падают каскадом. Это среда, не логика (до сбоя спеки
  зелёные). Разбор отдельно: ретраи/перезапуск драйвера, порядок спеков, чистка осиротевших процессов.
