## 1. Зачем

`docs/PLUGIN_API.md` (240 строк) — нормативный референс host-API Lua-плагинов. Он не поставляется
пользователю вместе с ПЕНАЛ, а агент, который пишет плагин, работает с промтом встроенного скилла
ассистента, а не с файлом из репозитория. Норма живёт в документе, которого у потребителя нет.

**Решение:** файл удалить. Нормативность переносится в **ADR-0042** + док-комментарии кода
(`crates/plugin-core`) + промты встроенных скиллов. `docs/PLUGIN_GUIDE.md` остаётся единственным
пользовательским документом о плагинах.

---

## 2. Решение по нормативности (ADR-0042)

Тело ADR-0027 **не трогаем**: прецедент проекта — ADR-0025 не переписывали, а пометили в шапке
`> **Частично заменён ADR-0037**` и вынесли норму в новый ADR. ADR-0042 амирует ADR-0027 §2.1–§2.2:

1. **Deprecated-пометка** (бывший п.7) — док-комментарий host-функции в `crates/plugin-core` + запись в ADR.
2. **Смена контракта** (бывший п.13) — код `crates/plugin-core` + промты встроенных скиллов
   (**`create-plugin`, `debug-plugin`**) + ADR. Промты живут в одном источнике —
   `crates/app/src-tauri/src/ai/skills/mod.rs` (`builtin_skills()`); фронтовая копия-фолбэк удалена
   (16.10.2026, TASK-008 вариант A), поэтому «правило синхронизации копий» в ADR не заводится.
3. **Ввод новой версии** (бывший п.16) — поднять `HOST_API_VERSION`, обновить промты, ADR, тесты.
4. **Адресат «реестра ADR» — `docs/adr/*`.** ADR-0027:68 и ADR-0041:12 ссылаются на несуществующий
   `DESIGN_DOC.md` §16 (нумерация §0–§13 заморожена) — считать ссылкой на каталог `docs/adr/`.
   §16 в DESIGN_DOC не создаётся.

Не пересматриваются: `HOST_API_VERSION` = 1, семантика версии, аддитивность, двухступенчатая
депрекация, контракт `plugin-core`, CLI, `plugins/index.json`.

## 5. Побочная правка

`docs/PLUGIN_GUIDE.md` §6 содержит баг: `local VIEW = host.plugin_id .. ":my-preview"` — функции
`host.plugin_id` не существует (промт скилла это знает, гайд врёт). Заменить на литеральный
`"<id>:my-preview"`.
