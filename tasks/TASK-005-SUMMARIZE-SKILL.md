## 1. Решение, которое требуется от владельца

**Рекомендация: вариант A — удалить `summarize` (подтверждено владельцем 16.10.2026).**

Пересечение с `explain` — одна секция из четырёх. Единственное уникальное содержание —
«Следующие шаги», то есть рекомендации к чужому документу: именно тот класс вывода, который
остальные промты прямо запрещают («не выдумывай»). Потеря покрывается свободным вопросом в чате
(«что дальше делать с этим документом?»).

## 2. Анализ

`EXPLAIN_PROMPT` — `crates/app/src-tauri/src/ai/skills/mod.rs:14-28`
`SUMMARIZE_PROMPT` — там же `:116-130`

| | Объяснить файл | Конспект |
|---|---|---|
| Роль | разборщик | составитель конспектов |
| Секции ответа | **4**: о чём (1–3 предл.) · структура · разметка · на что обратить внимание | **2**: тезисы (≤7) · следующие шаги |
| Правила | не выдумывать · не перепечатывать · пустой документ → одна строка | те же три дословно |
| Уникально | разделы 2, 3, 4 | только «Следующие шаги» |

Полной копии нет (6 правил совпадают 3, форма ответа разная), но отдельная кнопка не окупает
себя: уникально ровно одна секция, слабейшая по качеству, а «Объяснить файл» — более
очевидная кнопка в ряду. Плюс ряд из 6 кнопок (состояние после TASK-004) — уже шум.

**Стоимость удаления:** перечисления скиллов нет ни в одном документе (ADR-0032 задаёт формат,
не состав; в `docs/` слов «Конспект»/`summarize` нет) — трогаются только код и два теста.

## 5. Побочная находка: фолбэк `skills.ts` рассинхронирован

`crates/app/src/panels/aiPanel/skills.ts` содержит **только** `explain` и `create-plugin`.
Если хост не вернёт список скиллов, пользователь увидит 2 кнопки вместо 5 — без объяснения
причины. Это независимая проблема: фолбэк устарел.

Варианты: (а) актуализировать фолбэк под текущий состав — но тогда API-блок промтов дублируется
в 4+ местах (см. TASK-002 §5); (б) убрать фолбэк и показывать пустое состояние с подсказкой
перезапустить — тогда промт живёт в одном месте; (в) оставить как есть.

**Рекомендация: (б)** — устраняет дублирование целиком, а не чинит симптом. **Подтверждено
владельцем 16.10.2026 (TASK-008, вариант A): `FALLBACK_SKILLS` удаляется, промт живёт в одном
источнике.** Реализация — отдельная задача, вне объёма этого плана.
