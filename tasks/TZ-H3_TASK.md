# H3 — Экосистема (отдельная задача)

> **Статус:** Отложено (H1 и H2 реализованы, требуется отладка текущего функционала)
> **Приоритет:** Низкий
> **Зависимости:** Стабильная работа H1 + H2

---

## Контекст

H1 (ядро приложения) и H2 (плагинная система) реализованы. Перед началом H3 необходимо:
- Отладить существующий функционал
- Провести E2E-тестирование
- Убедиться в стабильности плагинной системы

---

## Задачи

### 1. Реестр плагинов
- [ ] Git-репозиторий с `index.json`
- [ ] Подпись Ed25519 для верификации
- [ ] Команда `darmark plugin install <url>`
- [ ] Команда `darmark plugin update`
- [ ] Команда `darmark plugin remove <id>`

### 2. Template-репозиторий плагина
- [ ] Создать шаблон для `darmark plugin init`
- [ ] Структура: `plugin.json`, `main.lua`, `README.md`
- [ ] Минимальный пример с `on_activate` + `host.show_message`

### 3. Тестирование плагинов
- [ ] Команда `darmark plugin test <path>`
- [ ] Запуск в изолированной среде
- [ ] Проверка манифеста, точек входа, permissions
- [ ] Отчёт о найденных проблемах

### 4. Расширение API
- [ ] Собрать обратную связь от реальных плагинов
- [ ] Выявить недостающие host-функции
- [ ] Расширить API по результатам

### 5. Опциональные улучшения
- [ ] Rust-undo (D5) — стек отмены/повтора на стороне Rust
- [ ] Редактор с подсветкой синтаксиса (требует отдельного ADR)

---

## Критерии готовности

- [ ] Реестр плагинов работает (install/update/remove)
- [ ] Подпись Ed25519 верифицируется
- [ ] `darmark plugin test` проверяет плагины
- [ ] Документация обновлена
- [ ] E2E-тесты для новых команд
